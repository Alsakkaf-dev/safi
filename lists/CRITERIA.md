# What goes on the Safi Arabic list

A site is listed only when a reviewer can point to public evidence for **at least two** of these:

1. **Copied or spun text.** Articles are lifted from other sites, or machine-translated with no editing.
2. **Mass production.** Publishing volume no real newsroom or author could produce, across unrelated topics.
3. **No accountable author.** No named writers, no "about" page with real people, no contact.
4. **Built for the search engine.** Pages exist to match queries (keyword-stuffed titles, answer-shaped pages with no answer).
5. **Reader-hostile.** The content is buried under ads, redirects or forced notifications.

## What never goes on the list

- A site because of its opinions, politics, religion, country or ownership.
- A site because it uses AI tools. The test is quality and honesty toward the reader, not the tool.
- A site on one person's say-so. Every entry links to the report where the evidence was reviewed.

## Process

1. Anyone opens a report (the "Report a site" issue form) with the domain, example pages and which criteria apply.
2. A maintainer checks the examples and replies in the issue.
3. If accepted, the domain is added in a commit that references the issue.
4. Site owners can appeal in the same issue. A fixed site is removed.

The list is plain text, so every addition and removal is visible in the history.
